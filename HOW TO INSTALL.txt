WHAT CHANGED
  1. Nearly real time. GitHub starts a scheduled run only every few hours. Now each run keeps
     building about every 10 minutes for up to 5.5 hours (a build takes about a minute). A new
     run replaces the one in progress; two never overlap.
  2. The BREAKING ticker is news: only US, World, Middle East and Business stories that several
     outlets carry or a Tier 1-2 outlet reports. Each line names its outlet and how many outlets
     carry the story. (Measured on the same news: the old ticker had 9 sports, culture or tech
     lines out of 19 and led with a video-game story; the new one has none, and 14 of its 20
     stories are carried by 2 or more outlets.)
  3. Each story once: a story that was in two sections now shows once, with an "also in" tag
     (42 repeated cards before, 0 now, on the same news).
  4. Straight to the article: 141 outlets' own feeds (BBC, NPR, Guardian, Al Jazeera, DW,
     France 24, CBC and more, each checked live), so their headlines open the outlet's page
     itself. 27% of the Read links now open the outlet directly (0% before); Google News stays
     as the fallback for the rest.
  5. The same top bar as Party Portal 3.2: SAVED, UPDATED, LIGHT, LIVE VIDEO, WAITING ROOM,
     then A- A+. Phones keep their own controls.
  6. While the page is hidden (another browser tab or another Argus tab) the silent video tiles
     pause; the tile being heard keeps playing.
  7. health.json is written each build (open https://nuzunews.github.io/health.json).
  Also in it (2.3.1, from ORDER-700): the heard tile held on a resize, TAB and ARGUS full
  screen inside Argus, Argus's accent colour in dark mode.
  Untouched: nuzu-bundle.js, sw.js, manifest.json, .well-known, twa-manifest.json and every
  Play Store file.

HOW TO UPLOAD
  1. Open https://github.com/NUZUNEWS/nuzunews.github.io
  2. Add file > Upload files. Drag in bot.py, version.json, CHANGELOG.md and README.md from this
     folder. Commit message, for example: "NUZU 2.4". Commit changes.
  3. Still on GitHub, open the folder .github, then workflows. Add file > Upload files. Drag in
     refresh.yml from this folder's .github\workflows folder (it replaces the old one).
     Commit changes.
  4. Actions tab > refresh > Run workflow (this starts the new loop at once).

CHECK (about 5 minutes after step 4)
  - https://nuzunews.github.io/ : the BREAKING ticker shows US, World, Middle East or Business
    stories, each ending with its outlet (and "N outlets" when several carry it).
  - Some headlines carry a small "also in ..." tag.
  - A BBC, NPR or Guardian headline's Read link opens bbc.co.uk / npr.org / theguardian.com.
  - https://nuzunews.github.io/health.json shows "version": "2.4.0".
  - Actions tab: the refresh run is still going after 15 minutes and shows "Build 2", "Build 3"...
